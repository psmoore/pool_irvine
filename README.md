# Irvine Aquatics — redesign preview

An unofficial redesign proposal for the City of Irvine's [Aquatics Centers](https://cityofirvine.gov/aquatics-centers)
pages. Every city link is kept. Every schedule is live from [Pool Relay](https://www.poolrelay.com), which holds the
fall 2026 pool allocation for all four pools (Woollett Competition, Diving and Teaching, and Northwood) lane by lane.

Run `python3 build.py` to regenerate the pages.
